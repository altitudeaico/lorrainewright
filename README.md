# Diaspora to Home - Website Repository

**Client:** Lorraine Wright MBE  
**Project:** Ghana Real Estate Investment Platform  
**Platform:** GoHighLevel (GHL)  
**Repository:** Backup and version control for website pages

---

## 📄 Pages in Repository

All pages use the `/new-` prefix convention as per GHL development standards:

1. **new-home.html** - Homepage with video background
2. **new-about.html** - About Lorraine (MBE, Oxford MBA, credentials)
3. **new-services.html** - 4 service packages + comparison table
4. **new-properties.html** - Property listings with filter system
5. **new-resources.html** - Free guides, blog, resources library
6. **new-contact.html** - Contact form and methods
7. **new-book-call.html** - Calendly booking integration

---

## 🎨 Design System

- **Fonts:** Montserrat (all pages)
- **Colors:** Navy #231B4F, Purple #7170B4, Beige #F5F1ED
- **JavaScript:** ES5-compatible for GHL
- **Navigation:** White bar, 55px logo, animated underlines
- **Mobile:** Full-screen overlay menu with body scroll lock
