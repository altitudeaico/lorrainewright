Free Guides — How to Add, Update & Manage

A step-by-step guide for updating existing free guides and adding new ones, including the funnel, form, delivery email and Resources page tile.

Overview

How the free guides system works

Each free guide on the site follows the same pattern. Understanding the pattern makes it easy to add new guides or update existing ones.

The journey for every free guide

Resources page tile

Links to the guide's landing page

→
/choose-your-guide

Or a dedicated landing page for the guide

→
Opt-in form

Name + email captures the lead into GHL CRM

→
Thank you page

Confirms the guide is on its way

→
Delivery email

GHL workflow sends the guide PDF link automatically

Each piece connects to the next. When you add a new guide, you need to set up all five pieces. When you update an existing guide, you typically only change the PDF link in the delivery email.

01

Updating an existing free guide

If you have a new version of a guide PDF and want to update what subscribers receive:

Step 1 — Upload the new PDF

1
Go to GHL → Sites → Media Storage
2
Upload the new PDF file. Give it a clear name: e.g. "Buy-Property-Ghana-Guide-v2.pdf"
3
Once uploaded, click the file to copy its direct URL. Save this — you'll need it in the next step.

Step 2 — Update the delivery email

1
Go to GHL → Automations → Workflows
2
Find the workflow for this guide. Look for names like "Free Guide — Buy Property", "Lead Magnet — Opt In" etc.
3
Open the workflow and find the Send Email step
4
Edit the email — find the download button or link and update the URL to the new PDF link you copied above
5
Save and publish the workflow
Test it: Submit the opt-in form with a personal email address and confirm the new PDF link arrives correctly.
02

Adding a brand new free guide

Follow these steps in order. Each step builds on the previous one.

Step 1 — Upload the guide PDF

1
GHL → Sites → Media Storage → upload the PDF
2
Copy the direct URL — you'll use it in the delivery email

Step 2 — Create the opt-in form

1
GHL → Sites → Forms → New Form
2
Name it clearly: e.g. "Free Guide — [Guide Name] Opt-in"
3
Fields: First name (required), Email (required). Phone is optional for free guides — keep the form short to maximise signups.
4
Style the form per the Forms Guide — Montserrat, 10px radius fields, navy submit button with 4px radius
5
Set the redirect on submit to your Thank You page (create one if needed — see Step 3)

Step 3 — Create a Thank You page

1
In GHL Sites, create a new page: e.g. /guide-thank-you or /[guide-name]-thank-you
2
Keep it simple: headline confirming the guide is on its way, a short note about what to expect, and a CTA back to the main site
3
Add the global nav and footer, publish

Step 4 — Create the delivery workflow

1
GHL → Automations → New Workflow
2
Name it: "Free Guide — [Guide Name] delivery"
3
Trigger: Form submitted → select your new opt-in form
4
Add action: Add Tag → create a tag for this guide: e.g. guide-buy-property guide-airbnb
5
Add action: Send Email → write the delivery email. Subject: "Your free guide is here, [First Name]!". Body: short warm message + a clear download button linking to the PDF URL from Step 1.
6
Optional: add a Wait (1–2 days) then a follow-up email pointing them to a relevant service or booking link
7
Publish the workflow

Step 5 — Add a tile on /choose-your-guide

1
GHL → Sites → open the /choose-your-guide page
2
Duplicate an existing guide tile in the page builder
3
Update: the guide title, a one-line description, the cover image, and the link (pointing to your new guide landing page or directly to the form)
4
Save and publish

Step 6 — Update the Resources page tile

1
GHL → Sites → open the /resources page
2
Find the "Free Guides" section → add or update a tile linking to your new guide
3
Save and publish
Before you go live: test the full journey. Submit the form with a personal email, confirm you land on the thank you page, and confirm the PDF link arrives in the delivery email within a few minutes.
03

New guide launch checklist

Use this every time you launch a new guide to make sure nothing is missed.

  • PDF uploaded to GHL Media Storage and URL copied
  • Opt-in form created (Montserrat, correct field and button styling)
  • Form redirect points to the Thank You page
  • Thank You page created, on-brand, nav/footer added, published
  • Delivery workflow created with correct trigger (the form)
  • CRM tag applied in the workflow
  • Delivery email tested — PDF link works, email arrives within 5 minutes
  • Tile added on /choose-your-guide
  • Tile added or updated on /resources page
  • Full journey tested end-to-end with a personal email
04

Tips for higher guide conversions

Keep the opt-in form short. Name and email only. Every extra field reduces signups. You can ask qualifying questions in a follow-up email instead.

Name the guide specifically. "The Ghana Property Buyer's Checklist" converts better than "Free Guide". Specific beats generic every time.

Use a real cover image. A mockup showing the guide as a physical booklet or PDF on a screen increases perceived value significantly.

Follow up. The delivery email is just the start. A 3-email sequence over 7 days — delivery, a related tip, and a soft CTA to book a call — consistently converts guide signups into qualified leads.

Tag consistently. Always apply a specific tag per guide in GHL so you can segment your list and see which guides are most popular. This data is valuable for deciding what content to create next.
