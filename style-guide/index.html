The single reference for how every page should look and behave — so new pages stay on-brand, and existing ones can be brought in line.

01

Colour palette

Navy gives structure and authority, purple marks anything interactive, beige is a restful background, and gold is a sparing highlight — never a background or body-text colour.

Buttons

Corner radius is always 4px. Primary buttons are purple (or navy on light sections); secondary buttons are outlined.

04

Global navigation

A white bar on every page (GHL supplies it site-wide). Logo left at 55px, uppercase links with 1.5px letter-spacing and 3rem gaps, and a purple "Contact Lorraine" CTA on the right.

Adding a dropdown

The nav is one block of custom code applied site-wide. To add a dropdown, copy an existing dropdown block (e.g. Properties), rename the label and change the child links, then re-publish. Because it's global, one change updates every page — always test on one page first.

05

Footer

Navy background, on every page. Link columns + a copyright row, the legal disclaimers, and the bright purple Workspace button that takes the team to the listings admin.

06

Layout & spacing

Content width

Max 1200px, centred, with ≥16px side padding on mobile.

Section rhythm

~4–5rem of vertical padding between major sections.

Cards

White, 12–16px radius, soft shadow — not hard borders.

Mobile

Everything reflows to one column; test at ~375px.

08

Self-service how-tos

Update the Featured Property

GHL → Settings → Custom Values → edit the "Featured …" values (name, price, image, gallery 1–6, etc.). It updates the homepage card and the Featured Property page automatically.

Swap a video

The video is a YouTube embed. In the page body, find the <iframe> and change its src to https://www.youtube.com/embed/VIDEO_ID — the ID is the part after youtu.be/ or watch?v=. Save & publish.

What the site search covers

Google-powered search over your public pages — their visible text, titles and meta descriptions. New or changed pages become searchable a day or two after Google re-crawls them.

Golden rules for GHL pages

Montserrat via @import; don't paste the nav/footer into a page (GHL adds them); keep custom JavaScript in the simple style we use; and always test on a fresh page before touching a live one.

09

Consistency checklist

Run every page against this — including pages created directly in GHL.

  • Correct global nav at top and footer at bottom
  • Montserrat only; no stray fonts
  • Palette matches Section 1; gold used sparingly
  • Buttons are 4px radius, correct colours
  • Heading/body sizes broadly match Section 2
  • Content within the 1200px container
  • Mobile: single column, nothing cut off at ~375px
  • Links work; no placeholder copy
  • Forms feed into the CRM and match the form pattern
