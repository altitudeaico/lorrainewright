02

How to create a new form in GHL

1
Go to GHL → Sites → Forms → New Form
2
Give it a clear name: e.g. "Contact — Main", "Rental Request Form", "Sell Property — Tier 1"
3
Add your fields. Standard fields for most forms: First name (required), Last name (required), Email (required), Phone (optional). Add any additional fields specific to your use case.
4
For each field: set the font to Montserrat, border radius to 10px, border colour to #D8D4EA, label weight to 600.
5
For the submit button: font Montserrat 700, background #231B4F, text white, border radius 4px.
6
Set the redirect (on submit): either a Thank You page, or "Stay on page" with a success message. Avoid leaving the default GHL success page — it's off-brand.
7
Set the notification: go to the form's Notifications tab → add an internal email notification to team@lorrainewright.co.uk so Lorraine knows when someone submits.
8
Connect to a workflow if needed: in GHL Automations, create or edit the relevant workflow and set the trigger to "Form submitted" → select your new form. This is how auto-replies and CRM tagging happen.
9
Embed the form on a page: in the GHL page builder, drag in a Form element and select your form from the dropdown. Or use the form's embed code in a custom code block.
Important: After creating a form, always test it by submitting a test entry. Check that: (1) the CRM contact is created, (2) the internal notification arrives, (3) any auto-reply sends correctly.

04

Common mistakes to avoid

!
Wrong button radius. GHL defaults to fully rounded buttons. Always change to 4px.
!
Wrong font. GHL defaults to its own font. Always change every field and button to Montserrat.
!
No internal notification. Without a notification, you won't know someone submitted. Always add a notification to team@lorrainewright.co.uk.
!
Default GHL success page. The default redirect after submission is an off-brand GHL page. Always redirect to a custom Thank You page or set a success message on the same page.
!
Too many fields. More fields = lower conversion. For lead capture forms, stick to name, email, and one qualifying question. Save the longer forms for when you actually need the data.
!
No test submission. Always submit a test entry after creating or changing a form. Check the CRM, the notification, and any auto-reply.
